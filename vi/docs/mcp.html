MCP

Model Context Protocol

Cho bất kỳ công cụ AI nào hỗ trợ MCP dùng chính Clark mà bạn đang trò chuyện. Các tool của nó gọi tới cùng gateway với REST API.

Endpoint

EndpointPOST /mcp trên node, ví dụ http://127.0.0.1:8765/mcp
TransportStreamable HTTP, response dạng JSON. Không có luồng SSE do server khởi tạo: GET /mcp trả 405.
Xác thựcAuthorization: Bearer <token>, cùng token với REST API.
Phiên bản giao thức2025-06-18 (ưu tiên), 2025-03-26, 2024-11-05
Methodinitialize, ping, tools/list, tools/call. Notification được nhận với 202.

Kết nối một công cụ AI

Qua HTTP

Dành cho client hỗ trợ MCP server từ xa có header. Tên khoá hơi khác nhau giữa các client; về cơ bản là một URL cộng với bearer header.

{
  "mcpServers": {
    "clarkcant": {
      "url": "http://127.0.0.1:8765/mcp",
      "headers": { "Authorization": "Bearer <token>" }
    }
  }
}

Qua stdio (Claude Desktop, Cursor, …)

Với client chỉ nói stdio MCP, clarkcant mcp là cầu nối stdio ↔ HTTP tới /mcp của node. Nó tìm node và token giống hệt CLI (CLARKCANT_URL, CLARKCANT_TOKEN, CLARKCANT_DATA_DIR).

{ "mcpServers": { "clarkcant": { "command": "node", "args": ["/path/to/clarkcant/apps/cli/src/main.ts", "mcp"] } } }

Các tool

ToolTham sốChức năng
ask_clark{ text, conversationId?, title? }Gửi tin nhắn cho Clark (tạo cuộc trò chuyện nếu chưa có) và trả về câu trả lời của Clark cùng conversationId, resolution, taskId.
list_conversations{}Liệt kê cuộc trò chuyện.
create_conversation{ title? }Tạo cuộc trò chuyện.
read_conversation{ conversationId, after? }Timeline dạng văn bản kèm nội dung có cấu trúc.
answer_question{ conversationId, questionId, text?, optionIds?, confirmed? }Trả lời câu hỏi mà Clark đặt ra; confirmed dùng cho câu hỏi có/không.
stop_all_work{}Giống POST /stop.
node_status{}Giống GET /node.

Cố ý không có tool phê duyệt. Phê duyệt nằm trên giao diện của chính người dùng. Một client AI không được phép tự phê duyệt hành động cần kiểm soát của chính nó.

JSON-RPC thô

MCP client làm việc này thay bạn. Để xem định dạng trên dây, hoặc gọi tool từ script:

curl -s -X POST "$CLARKCANT_URL/mcp" \
  -H "Authorization: Bearer $CLARKCANT_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{ "jsonrpc": "2.0", "id": 1, "method": "initialize",
        "params": { "protocolVersion": "2025-06-18", "capabilities": {},
                    "clientInfo": { "name": "my-app", "version": "1.0.0" } } }'
curl -s -X POST "$CLARKCANT_URL/mcp" \
  -H "Authorization: Bearer $CLARKCANT_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{ "jsonrpc": "2.0", "id": 2, "method": "tools/list" }'
curl -s -X POST "$CLARKCANT_URL/mcp" \
  -H "Authorization: Bearer $CLARKCANT_TOKEN" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{ "jsonrpc": "2.0", "id": 3, "method": "tools/call",
        "params": { "name": "ask_clark",
                    "arguments": { "text": "how do I connect Cursor to you?" } } }'
